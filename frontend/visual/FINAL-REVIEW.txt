UI REFRESH — FINAL LOCAL REVIEW

Implemented the selected A layout with B's serif display typography and
“Genetics, with context.” Kept the existing palette. Manrope and Newsreader are
self-hosted, licensed, and bundled through existing public assets. No serving
routes or CSP changes were needed.

The workspace leads with the current reported step, a plain explanation, elapsed
time against the user's 70–100 minute estimate, and whether an answer is needed.
The moving DNA illustration uses one CSS transform, slows when waiting, pauses
in hidden tabs and becomes static under reduced motion. A question leads the
screen, changes the tab title and makes an assertive announcement. Sound and
notifications require opt-in; permission denial is handled. Typed answers and
focus survive polling. Raw event notes live inside native technical details.

The result leads with the exact delivered percentile, then the actual reference
comparison, evidence and delivered limits. Small raw distributions use every
recorded score as a dot; large distributions use complete counts in bins. If the
run provides only quantiles, the chart labels those recorded ranges instead of
inventing a distribution. The patient's recorded score is marked. No reported
score, percentile, coverage, warning, refusal or explanation is changed.

Data limitations
- No per-chromosome completion events reach the browser. Imputation's chromosome
  detail exists in tool stderr/final artifacts, while public progress events
  expose only stage/kind/time/text/outcome. No chromosome display was invented.
- Remaining time is an estimate, not a completion percentage. It requires a real
  retained run_started timestamp. Missing start time suppresses the countdown.
- The separate nginx service-outage page is unchanged. Its response string cannot
  accommodate the fonts within nginx's configuration token limit; updating its
  serving configuration is beyond the permitted page-text scope. The disconnected
  workspace state is redesigned, captured and tested.
